## 一、部署前第一课：为什么优先选“旁路由”而不是直接拆掉主路由？

第一次玩软路由最容易犯的工程大忌，就是兴冲冲买台迷你主机把家里光猫桥接、PPPoE 拨号、Wi-Fi AP 和透明代理插件全部硬塞进同一台机子里。结果深夜一不小心点错一个 `nftables` 防火墙参数或者订阅更新格式崩溃，家里老人看不了电视、家人手机全部断网，半夜还得摸黑拿网线插笔记本抢修。

采用“**主路由稳固拨号 + OpenWrt 旁路由接管代理**”的分离结构，具备压倒性的容错优势：
- **断电降级零痛苦**：旁路由哪怕彻底拔电源关机或重刷固件，需要用到加速的几台设备把网关切回主路由即可秒恢复全部网段连通；
- **按设备按需接入**：电视盒、工作笔记本、开发主机连旁路由自动出海；家人的微信刷剧设备、扫地机、智能门锁留在主路由稳稳本地直连，互不消耗流量配额。

## 二、准备清单：动手前的四个必查前置条件

1. **确认品牌订阅形式（最关键门槛）**：你的机场账户必须能在后台直接复制 **Clash 订阅 URL** 或 **通用 V2Ray/sing-box 订阅链**（可在[品牌列表](/brands/)通过筛选“支持第三方”确认）。
2. **决定要用的核心插件**：在看清楚自己的路由器内存与 OpenWrt 固件版本号后，参照 [OpenWrt 24.10 插件选型比较](/articles/openwrt-nikki-vs-openclash/) 选好其中一套，**严禁在同一台路由上同时激活两个透明代理插件（会互抢 7890/TPROXY 端口直接挂死）**。
3. **网口与静态网段规划账本**：提前定死三个明确局域网地址：
   - 主路由 IP（假设为 `192.168.1.1`，开启主 DHCP 服务器）；
   - OpenWrt 旁路由固定静态 IP（设置为同网段不冲突地址，如 **`192.168.1.2`**）；
   - 旁路由的网关与默认上行 DNS 先指向主路由 **`192.168.1.1`**。

## 三、标准旁路由接线与系统设置 5 步走

### 第 1 步：物理网线接入主路由 LAN 口
把刷好 OpenWrt 系统的设备（x86 小主机或单口 ARM 软路由）用一条网线直接插进你家现有无线主路由背面的任意一个 **`LAN`** 口即可（不需要占 WAN 口）。

### 第 2 步：设定 LAN 静态地址并关闭旁路由 DHCP
电脑手动改好同网段地址进入 OpenWrt LuCI 管理后台（接口 → LAN → 修改）：
1. 协议选 **`静态地址 (Static Address)`**；
2. IPv4 地址设为 `192.168.1.2`，子网掩码 `255.255.255.0`；
3. **IPv4 网关** 填入你家主路由地址 `192.168.1.1`；
4. **使用自定义的 DNS 服务器** 填入 `192.168.1.1`（或 `223.5.5.5`，避免循环指向自己）；
5. 切到下方 `DHCP 服务器` → **`勾选“忽略此接口”`**（关掉旁路由重复发 IP 功能！一家网络只能由主路由这一个管家发 IP）；
6. 如使用单个物理网口跑通内网旁路由转发，在防火墙 LAN 区域确认开启或按需检查 `IP 动态伪装（Masquerading）`，并排查无线设备切换包时是否需关闭不兼容的“SYN-flood 防御”以防丢包。

### 第 3 步：在插件内导入订阅与核对规则
1. 打开你选好的插件（以 Nikki 或 OpenClash 为例），粘贴机场后台复制出的 **Clash 订阅链接**；
2. 更新并测试一次内核下载（如果还没能出国下载内核，可先从电脑挂节点在官方 GitHub Release 下好 `mihomo` 二进制手动上传到插件指定路径）；
3. **重点打开两项保护**：
   - 运行模式设为 **`Fake-IP（增强）`** 或配合稳定 `Redir-Host`（详参 [DNS 模式与泄漏对照](/articles/fake-ip-vs-redir-host-dns-leak/)）；
   - 确保插件内置了 **“绕过大陆 IP 列表（China IP Bypass）”**，防止家里看 B 站 4K 或网盘同步走过代理把你购买的几百 GB 流量几天内一扫而空！

### 第 4 步：单设备手动指定测试验证（Apple TV / 电脑 / iPhone 实操）
先别去动主路由 DHCP 设置！挑一台你想加速的设备（例如书房 MacBook 或客厅 Apple TV）做单机试水：
- 进入该设备的 Wi-Fi / 以太网设置 → 将 IP 配置改为 **手动（Manual）**：
  - 设备 IP：分配一个不在主路由自动分配池内碰撞的值（如 `192.168.1.188`）；
  - 子网掩码：`255.255.255.0`；
  - **路由器 / 默认网关**：填 **`192.168.1.2`**（指给 OpenWrt 旁路由）；
  - **DNS 服务器**：填 **`192.168.1.2`**。
- 打开浏览器先测国内门户（确认依然高速低延迟走直连），再开 YouTube 与目标流媒体检查流畅度，全顺再给第二台需要翻墙的主机这样改。

### 第 5 步：观察 48 小时无报错后，再决定是否推给全家 DHCP
如果全家日常设备（含智能电视、Pad）都希望无需手动一个个输 IP 直接上外网，跑满 48 小时不卡微信、不掉本地网银后，再登录主路由后台把 DHCP 下发项里的“默认网关与 DNS”改填为 `192.168.1.2`（依然建议把家里老人机的 MAC 绑定排除或手动填回主路由 `192.168.1.1` 保平安）。

## 四、软路由日常运行中的 3 个高频翻车点避坑

1. **BT/PT 下载与网盘挂载千万别进透明代理端口**：很多 NAS/软路由合一机器在同一台硬件上挂着 qBittorrent。如果不配置端口放行或 IP 绕过，海量 P2P UDP 连接数分分钟把代理内核和机场出口打满封号，必须设置“NAS 下载机 IP 直连不经过插件核心”！
2. **多台设备并发共享下的协议流量算账**：当家里四台设备同时用着旁路由看 4K 视频，流量全部扣在同一个机场套餐头上；因此购买前要优先关注像[光速云极速版/流光版（不限设备+1x倍率）](/brands/guangsuyun/)或[星岛梦（全线1x+不限设备）](/brands/xingdaomeng/)等不严卡单终端同时并发上限的套餐，切勿用 60GB 小包撑全屋大屏观影。
3. **升级固件一定备份现有 `config.yaml` 与覆写规则**：每次重刷 OpenWrt 系统都会清干净第三方插件，记得把插件目录下自己调了半天的规则、ACL 分流清单与机场备用节点 URL 存一份到电脑硬盘。

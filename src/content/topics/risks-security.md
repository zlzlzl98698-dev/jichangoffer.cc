## 一、机场代理的真实隐私边界与“绝对红线防御清单”

用下面一张清晰的权限隔离表，把日常跨境上网时“机场看得到什么”与“你绝对必须守住哪三条线”划分清楚：

| 数据与安全环节 | 机场运营商服务端能看见吗？ | 我们自己必须死守的实操防线 |
| :--- | :--- | :--- |
| **你访问的目标域名主机名** *(如 `youtube.com`)* | **看得到**（TLS 握手明文阶段传递 SNI 域标与流量字节数） | 正常现象，这是代理路由转发工作必需；避免在任何节点进行无意义恶意扫描发包 |
| **HTTPS 页面内部表单、账号密码与消息正文** | **彻底看不到**（受浏览器端到端高强度加密死锁保护） | ① 遇到浏览器弹“**证书不受信任 / 隐私错误**”红警告立刻点关闭逃离；<br>② **死活绝不安装任何来路不明软件弹窗索要安装的“自定义系统根证书”** |
| **电脑桌面文件系统、剪贴板、浏览器已存密码** | 节点本身碰不到；**但黑产假安装包 / 带毒闭源客户端看得到！** | ① 开源端一律去 **GitHub 官方仓库** 或 **海外区 Apple App Store** 核实源头下载；<br>② 禁用“免费破解版”和谷歌商店遭第三方接管的异常应用 |
| **你在机场面板注册填进去的电子邮箱和登录密码** | **站方后台数据库存有记录** | 注册小众网站一律开启密码管理器使用**完全独立的 16 位随机废密码**，哪怕将来万一泄漏库表也绝对撞不进你的任何个人重要账号！ |

## 二、日常安全核查“五条铁律”（照做即可放心上外网）

1. **开源软件绝不走百度的普通中文高速下载站点**：只认 [客户端大全页](/clients/) 核验好列出网址的正版官方源头；
2. **手机苹果端守住“App Store 与系统 iCloud 分离”**：绝不在系统灰色设置页登录外人发过来的 Apple ID；
3. **关闭浏览器自研安全 DNS 与防漏保护**：在开启客户端 [TUN 模式](/tutorials/tun-mode/) 的基础上按 [DNS 排查步骤](/troubleshooting/dns-error/) 验证一遍无中国运营商 DNS 旁路直漏；
4. **切忌晒带 `token=` 完整链接的微信群求助图**：截图报障务必顺手马赛克涂黑完整订阅链接，泄露即立刻点后台「重置链接」；
5. **尽量回避毫无营收闭环、却宣称永久完全不限流不限速的免费小软件**：免得手机悄无声息变成别人的免费爬虫代理出口池（参考：[免费 VPN 危害揭示](/vpn/free/)）。

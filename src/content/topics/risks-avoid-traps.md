## 一、下单前必做 60 秒 6 项防踩坑 Checklist

每次接触新服务打算微信/支付宝扫描支付那一刻，花一分钟对照以下 6 个方块逐一过目打勾：

- [ ] **已明确查对实际付款总金额与计费周期**：区分清楚是“单月付款 ¥19.9”还是“年付均摊、实扣 ¥96”；
- [ ] **已确认客户端兼容性完全符合自己需求**：若要用 Clash Verge Rev / 小火箭 / Karing / OpenWrt 软路由，确认其开放第三方标准通用订阅 URL；
- [ ] **已检视常见主力节点倍率规则**：没踩进日常节点动辄 `3x`、`5x` 暗中烧流缩水黑坑；
- [ ] **已认清非港节点才可用主流 AI**：如果买来主要是为了用 ChatGPT / Claude / Gemini，确认该套餐包含**新加坡、日本或美国节点**且能自己选组锁定；
- [ ] **软件一定是从核对过的 GitHub 官方仓库 / 正规海外区苹果商店安装**：不轻信任何百度中文下载站、不往手机系统 iCloud 登陌生 ID；
- [ ] **首次买陌生站点严格控制单笔金额**：先试单月付，或者看清楚其官网是不是明文写着 **“虚拟订阅商品一旦使用概不退款”**，把最大潜在后悔控制在二三十元以内！

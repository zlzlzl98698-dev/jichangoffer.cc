## 一、故障范围定责模型：5 分钟分清本地问题还是服务端停摆

**故障症状**：节点列表延迟检测全标红色 `Timeout` / `Err`、或者右下角刷新订阅跳出各种英文红色弹窗。

按照**由简到繁、从本地到远端**的高效排障逻辑走完这五个判断步骤，能解决绝大多数突发断网情况，避免盲目买新套餐白花冤枉钱。

---

## 二、准备与检查前置步骤（1 分钟必做）

在怀疑软件 Bug 或机场倒闭前，先快速确认以下两项基础事实：
1. **检查电脑与手机时钟精确度**：
   - Windows：右键桌面最右下角时间 → `调整日期和时间` → 点击 **`立即同步`**；
   - macOS：`系统设置 → 通用 → 日期与时间` 勾上自动设置；
   - 验证点：把北京时间到秒校准在误差 30 秒内！只要时间快慢超过一两分钟，所有现代加密协议的防重放校验与证书时效全部直接报错拒绝握手。
2. **用手机蜂窝网络做 A/B 交叉确认**：
   - 关闭手机 Wi-Fi，用 5G/4G 流量开同一份订阅测通性。这一步直接帮你砍掉一半错误方向。

## 三、按症状分类排查实操手册

### 情形 1：客户端刷新/导入订阅失败（常见报错词速查与破解）

请对照你软件弹出框里（或左下角黑框日志里）出现的英文原文对症操作：

| 报错提示核心字样 | 背后发生的技术故障 | 立即有效修复方法 |
|---|---|---|
| **`dial tcp 127.0.0.1:7890: connectex: No connection...` 或 `connection refused`** | **死循环陷阱！** 电脑开着“系统代理”占用了端口，但软件内核其实还没连上节点或端口冲突，导致它自己经过自己去拉订阅直接碰壁 | 1. 去系统或客户端关掉 **「系统代理 (System Proxy)」** 和 **「TUN 模式」**；<br>2. 右键目标订阅设置，确认是否误勾了“通过代理更新”，改为纯直连更新 |
| **`TLS handshake timeout` / `unexpected EOF` / `x509: certificate has expired`** | ① 原先那个旧订阅网址的域名在国内被墙拦截或证书过期换了新域；② 当前宽带出口在抢握手阶段阻断了连接 | 1. 改用手机 5G 网络或者挂一个临时可用的备用节点，点一次通过代理更新订阅；<br>2. 上官网或发布页看商家有没有切换新订阅域名，更换新的 URL 重新导入 |
| **`403 Forbidden` / `404 Not Found`** | **令牌被重置或订阅过期失效**：你之前在机场面板按过一次“重置订阅链接”，老 URL 已作废；或者旧套餐到期彻底清账了 | 重新登录官网面板，核查到期时间、已消耗流量配额，确认后复制一条崭新的订阅 URL 覆盖新增 Profile |
| **`unsupported proxy type` 或解析报配置错误 (`yaml: line...`)** | **客户端老旧不支持新协议！** 比如机场已经切去 `VLESS-Reality` 或 `Hysteria 2`，而你的电脑还在用几年前早被作者停更删除的老版本 Clash for Windows / 老 v2rayN | 不要到处找偏方改节点文本！直接下载并安装官方最新主线版 **Clash Verge Rev / FlClash / 新版 v2rayN**，旧文件全部换新内核立刻正常 |

### 情形 2：订阅拉下来了，但全部节点延迟显示红字超时（Timeout）

如果订阅能正常刷新（说明流量未到期且与面板服务器通信顺畅），可节点条条都红，依次查这四条：

1. **检查客户端里的“协议筛选与版本兼容”**：如果是老牌多节点混搭（比如一翻云同时有 SS、Hysteria 2 和 Reality），发现只是其中标 `Hy2` 的红一片而标 `VLESS` 的全绿，说明你当前的宽带环境（如宿舍/酒店）严苛封杀或限速 UDP！切换走 TCP 443 通道的节点即可解决，详见[校园网与企业内网协议攻略](/articles/campus-enterprise-network-protocols/)。
2. **检查机场流量余量是否正好清零（尤其是有高倍率的节点！）**：有些节点虽然套餐显示 300GB，但不注意连了特定标注 `5x`、`10x` 的昂贵专线跑了个大包，半小时就扣光所有配额导致全线踢断。上官网后台看一眼真实余额！
3. **测试工具和网关“假红灯”辨识**：在 Shadowrocket 或部分客户端下，如果设置了仅发 `ICMP Ping` 包，部分中转服务器机房为了安全会直接屏蔽 ICMP 探针，导致画面看着全红超时、其实点开网页速度飞快！把测试方式改为 `TCP CONNECT` 或 `URL Test (HTTP)` 再测一遍。
4. **排查是否同时挂着两款杀软/加速器/防火墙驱动**：杀掉电脑管家自带的广告网盾、暂停冲突的游戏加速器、停掉公司 VPN 软件再重测一次。

### 情形 3：系统全部断开（不仅 Google 挂了，连微信、国内网页也集体掉线）

这几乎可以断定是客户端异常离开或模式冲突引起本地系统网口瘫痪：
1. **Windows 清理残留系统代理**：同时按 `Win + I` 打开系统设置 → `网络和 Internet` → `代理` → 查看最下方 **“手动设置代理”** 的开关是不是明明客户端早已关闭了它却还保持开启！将其手动拨至关闭！
2. **清除 Fake-IP 虚拟 IP DNS 污染缓存**：如果在开启 Fake-IP 状态下软件异常崩溃，浏览器还抓着 `198.18.x.x` 不放。打开 Windows 命令提示符 / 管理员 PowerShell 跑一行 `ipconfig /flushdns`（Mac 执行 `sudo killall -HUP mDNSResponder`）再重启浏览器即复原。
3. **停用残留虚拟网卡**：如果开过 TUN 模式发现怎么都断网，去 Clash Verge Rev 的设置页确保 **关闭 TUN 模式** 甚至在系统“网络适配器设置”里核实残留虚拟网卡（如 Meta / sing-box / Wintun Tunnel）是否正常退回。

## 四、成功恢复验证清单

按照上面修补完成后，照着下面三步做闭环验收才算稳妥：
1. **单线直通检验**：先关闭全部额外规则脚本测试默认 `节点选择` 下一个延迟绿色的普通香港/新加坡节点，确保 Google 网页与国内站都能独立打开；
2. **重刷更新订阅确认**：保持当前能通的状态点一次「更新订阅」，看到返回绿色的成功提示与最新流量统计条（代表本地更新通道以后畅通）；
3. **为防下一次重演留出后路**：如果你工作学习高度依赖实时外网不能承受单家机场突然 48 小时波动，平时花百来块买份异源的[不限时永久流量包](/pricing/unlimited-time/)当第二份 Profile 存着，遇到突发全超时一秒切备胎就能立刻恢复工作，事后再慢悠悠排查故障原因。

## 五、如果全部方法都排查完，手机 5G 和家里宽带仍然全红 48 小时？

当你跨运营商验证过、时间校准过、换新客户端测试过、甚至发现官方发布页与工单整整两天没有任何维护回音时，基本可以判定进入了**高危长期断服状态**。此时不要耗在里面等奇迹发生，立即按照[机场跑路前兆自查与 15 分钟迁移指南](/articles/airport-exit-scam-migration-checklist/)保全支付留痕、寻找异源替代品牌平滑迁移。

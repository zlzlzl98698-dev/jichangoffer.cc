## 一、30 秒快速诊断分流表：按症状直接找根因

不要一遇到断网就到处重装系统或者盲目在群里问“这软件是不是废了”。请先对照下表第 1 列定位此刻桌面或手机上出现的准确现象，按顺序跳过排除即可：

| 常见故障现象（看屏幕表现） | 排名第一最高发原因（80% 概率落这里） | 第二高频与环境原因 | 立即生效的直给修复操作 |
| :--- | :--- | :--- | :--- |
| **所有节点全部红字 `Timeout`** | ① 电脑时间与北京标准时间误差超过 1 分钟；② 机场套餐刚刚过期或当月流量已提前耗尽 | 机场后台批量换了中转域、老节点端口全失效，而你一个月没更新订阅 | 1. 进系统设置点击「立即同步时间」；<br>2. 登录官网查剩余流量；<br>3. 关代理更新一次订阅 |
| **点更新订阅报 `Network Error / EOF`** | 软件此时还开着「系统代理」试图走一条死节点去拉取新配置，造成死循环 | 当地宽带 DNS 污染拦截了机场主站域名，或机场防刷盾拒收客户端 UA | 1. **先彻底关闭「系统代理」再点更新**；<br>2. 手机开 5G 热点拉一次订阅；<br>3. 勾选订阅设置里的“使用代理/切换 Clash UA” |
| **节点绿灯有延迟，浏览器什么都打不开** | 后台同时开了**两个**代理客户端/游戏加速器冲突，或上次强制关闭残留了僵尸系统代理配置 | 浏览器启用了自带的实验性 DoH / 扩展插件强行覆写了系统代理端口 | 1. 任务管理器彻查杀掉多开冲突软件与加速器；<br>2. 在本客户端连续开关一次「系统代理」刷新注册表 |
| **国外站点顺滑，国内微信/淘宝极慢** | 错点成了 **`Global（全局模式）`**，导致本来该直连的国内网也绕道海外飞一圈 | Fake-IP 与公司局域网内网域发生地址池碰撞，或分流规则损坏丢失 | 1. 主界面立即切回 **`Rule（规则模式）`**；<br>2. 确保未删除内置直连 GeoIP 规则文件 |
| **浏览器通畅，但命令行/终端 `git/npm` 超时** | 只开了基础的「系统代理（System Proxy）」，命令行与部分桌面软件不读取系统代理设定 | 软件没有管理员级驱动权限或系统服务未启动 | 进设置先点「安装服务模式（Service Mode）」，随后直接开启 **TUN 虚拟网卡模式** |
| **开 TUN 模式报错启动失败 / 找不到核心** | Windows 杀毒软件（如部分第三方安全卫士）把核心可执行文件 `mihomo.exe` 当成黑客工具误删隔离 | Windows 未能完成 UAC 权限提升安装系统服务，或与 Hyper-V/WSL 虚拟网桥口冲突 | 1. 进杀毒软件“恢复与信任区”还原客户端安装目录；<br>2. 右键「以管理员身份运行」点一次服务模式修复 |
| **桌面工具一双击打开白屏、闪退** | Windows 缺少或损坏了现代桌面界面必需的 **Edge WebView2 Runtime** 组件 | 旧配置文件存在格式 syntax 错误造成界面加载阻塞 | 1. 从微软官网下载安装 **Edge WebView2** 独立包；<br>2. 备份后清空客户端配置目录重新导入订阅 |

## 二、深入排查三步走：从本地端到上游链路的系统化排雷

### 关卡 A：校准物理底层（时钟、杀软与端口占坑）

1. **Windows + Linux 双系统用户的世纪老坑：硬件时钟不同步**：
   由于 Windows 默认主板 CMOS 存本地时间而 Ubuntu 等 Linux 存 UTC 零时区时间，每次重启切回 Windows 电脑右下角常常会直接快出或慢出 **8 个小时**。Shadowsocks-2022、VMess 与 TLS 证书校验对两端时钟容错极限通常只有 **90 秒**，一旦时间对不上，100% 全军覆没报错 `Timeout`。右键任务栏时间点开「调整日期和时间 -> 立即同步」一秒治愈。
2. **杀软隔离误杀检查**：
   千万别盲目点杀毒弹窗的“一键清理”。开源引擎 `mihomo.exe` 与 `sing-box.exe` 负责创建加密传输通道，部分安全软件的启发式规则会粗暴把内核核心误报隔离。把整个客户端所在文件夹添入杀毒软件**排外/信任白名单**后再修复打开即可。
3. **清理残留代理端口（“假死断网急救术”）**：
   如果你卸载了旧软件却彻底连不上国内网（但微信可能奇迹般还能发文字消息——微信会尝试直连探测，而 Chrome 等严格按系统代理走的软件全挂）：打开系统“设置 -> 网络和 Internet -> 代理 -> 手动设置代理 -> 确认设为**关闭**”。Mac 用户在“系统设置 -> 网络 -> 当前 Wi-Fi 详细信息 -> 代理”里把所有勾选上的 HTTP/HTTPS/SOCKS 代理勾全部取消并点好即可立刻恢复正常联网。

### 关卡 B：攻克订阅更新与 DNS 解析泥潭

1. **更新订阅卡死的三连招**：
   - 第 1 招：切掉软件自身系统代理和 TUN 开关再刷新（详情阅读：[订阅异常修复专项攻略](/tutorials/subscription/subscription-troubleshooting/)）；
   - 第 2 招：检查官网是否最近换过了“最新防屏蔽订阅域名”（数据库里如光速云、星岛梦等老牌团队在特殊日期通常会公告最新备用面板网址；也请查看 [官网与链接异常处理汇总](/brands/official-links/)）；
   - 第 3 招：电脑连了学校宿舍网关打不开国外域名拉订阅时，**手机拔出 Wi-Fi 用 5G 流量开个人热点给电脑连 10 秒钟**把最新订阅配置文件拉进硬盘，拉完再切回宿舍 Wi-Fi 即可。
2. **解开 Fake-IP、DNS 污染与“部分网页死活刷不出”**：
   - **现象**：能连上外网，但打开公司内部管理系统、`192.168.1.1` 路由器后台或者某些国内银行控件时异常失败。
   - **机制与处置**：大多数现代 Mihomo 规则默认打开 `enhanced-mode: fake-ip` 来极速加速解析域名（分配 `198.18.0.0/16` 虚构 IP 段）。假如公司内网程序傻傻把这些假 IP 缓存死了或者与其它 VPN 工具争抢网段，就会失灵。在自定义配置里将对应内网后缀加进 `fake-ip-filter` 跳过名单，或按 [Fake-IP 与 DNS 泄漏深层分析](/articles/fake-ip-vs-redir-host-dns-leak/) 里的说明排错排查浏览器内部是否抢先打开了自己的“安全 DNS（DoH）”功能。

### 关卡 C：在复杂网络（高校校园网/公司强限内网）下破局

如果你的机场账号在家里宽带和手机 5G 上全部生龙活虎，唯独带到**大学寝室校园网**或者**公司大楼 Wi-Fi** 就全盘失效（参见：[校园网与企业内网网络限流及协议适配指南](/articles/campus-enterprise-network-protocols/)）：

1. **别忘了先完成校园网 Web 页面认证**：没点校园网登录认证页时，网口所有流量都会被强制劫持到内网提示页面，此时开代理会报奇怪的证书警告报错；
2. **针对性切换端口与协议**：校园网经常粗暴丢弃全部高并发 UDP 端口流量并紧盯老旧端口。从列表里刻意挑出基于 **TCP 443 端口的 Trojan 或 VLESS-Reality 节点** 往往比基于 UDP QUIC 的 Hysteria2 稳十倍；
3. **切勿同时叠开“学校远程连校园内网 VPN（EasyConnect 等）”与桌面机场代理**：EasyConnect 类软件自身带驱动级别强劫持路由，如需用校园图书馆知网资源，建议用专用虚拟机、独立浏览器或彻底关闭代理端后再使用。

## 三、如何确认“确实是上游机场出故障了，不是我的锅”？
